# 加密与脱敏特征基线

系统内置 2 条脱敏特征和 25 条加密/摘要特征，用于样本值识别。首次升级到该版本时，后端会按稳定的特征编码补充缺失项；同编码的已有配置不会被覆盖，升级完成后用户删除的内置项也不会在每次重启时自动恢复。

## 脱敏特征

脱敏方式只保留两种通用形态：字段值任意位置出现至少一个半角星号 `*`，或至少一个半角井号 `#`。规则不再按手机号、证件号、邮箱等业务对象拆分，因此同一条规则可覆盖任意数据类型和任意掩码长度。

## 加密特征

基线覆盖以下可从文本值中稳定观察到的格式特征：

- MD5、SHA-1、SHA-256/SM3、SHA-384、SHA-512 十六进制摘要；
- bcrypt、Argon2、scrypt、PBKDF2、SHA-crypt，以及 PostgreSQL、MySQL、SQL Server、LDAP 常见口令哈希；
- OpenSSL Salted、Fernet、JWT、JWE、PKCS#8/传统加密私钥 PEM、OpenPGP Armor；
- 版本化 AEAD、显式 `ENC(...)` 包装、长十六进制与长 Base64 兜底形态。

## 识别边界

这些规则识别的是值的外观格式，不负责密码学验证。相同长度的摘要可能来自不同算法，例如 SHA-256 与 SM3 都常表示为 64 位十六进制字符串；Base64 也只是编码，不能单独证明值已加密。系统因此将通用十六进制和 Base64 规则设置为较低命中率，实际结论仍应结合字段名称、数据来源和保护策略复核。

## 参考依据

规则格式按公开规范及主流实现的可观察文本结构整理，主要包括 PHC 字符串格式、RFC 7516（JWE）、RFC 7519（JWT）、RFC 7468（PEM 文本编码），以及 PostgreSQL、MySQL、SQL Server 和 LDAP 的口令存储格式。基线只保存可用于扫描的格式特征，不保存密钥、盐值或任何真实敏感数据。
